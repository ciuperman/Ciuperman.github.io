Despre

Ce este Ciuperman

Nu este o corporație. Este un nume sub care se adună desene, filme scurte și note din zonă de munte.

Ciuperman pornește din pădure: ciuperci, poteci, vreme și un personaj care merge printre ele. Tonul e serios față de natură și lejer față de sine.

Site-ul este baza publică. Poveștile lungi trăiesc pe video; aici rămân cadrul, numele și punctul de contact.

English: Ciuperman is a forest character and a quiet place for stories — not a shop, not a pitch deck.

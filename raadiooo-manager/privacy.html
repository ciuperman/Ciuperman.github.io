Privacy Policy

Last updated: October 7, 2026

Raadiooo Manager is a personal tool used only by the owner of the YouTube channel Raadiooo to manage that channel.

What data is accessed

With the owner's authorization, the app uses the YouTube Data API to read the owner's channel and video information (such as titles, descriptions, statistics and visibility) and to update the owner's own videos.

How data is used and stored

Data is used only to manage the owner's channel. OAuth tokens are stored privately on the owner's own machine. No data is sold, shared with third parties, or used for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Privacy Policy

Last updated: October 7, 2026

Raadiooo Manager is a personal tool used only by the owner of the YouTube channel Raadiooo to manage that channel. It has no other users.

YouTube API Services

Raadiooo Manager uses YouTube API Services (the YouTube Data API). By using it, the owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

With the owner's OAuth authorization, the app uses the YouTube Data API to:

  • upload the owner's own videos and Shorts to his channel;
  • set and update titles, descriptions, tags, thumbnails and visibility (private, unlisted or public) of the owner's own videos;
  • upload, update and list caption/subtitle files for the owner's own videos;
  • read the owner's own channel and video information and statistics (such as titles, descriptions, view and like counts, visibility).

The app does not access other people's channels or data, and it never asks for or stores YouTube/Google passwords.

How data is used and shared

Data is used only to carry out the owner's own instructions for managing his channel. Every upload or change is made only when the owner asks for it, and visibility is always chosen by the owner.

Cloud AI processing: the tool is operated through a cloud-hosted AI assistant service provided by a third party. To perform the owner's requests, channel and video metadata (such as titles, descriptions, tags, caption text and statistics) and, where needed for a request, the files being uploaded may be processed by that AI provider, under the provider's own terms and privacy policy. This processing happens only to carry out the owner's own instructions.

No data is sold, used for advertising, or shared with anyone else. The app does not serve ads or third-party content and does not use cookies or tracking technologies.

Storage, retention and deletion

  • OAuth tokens are stored privately on the owner's own device and are used only for the purposes described here.
  • Any YouTube API data cached by the tool (for example video metadata or statistics) is kept for at most 30 days, after which it is deleted or refreshed.
  • If access is revoked, the stored tokens and all stored YouTube API data are deleted within 7 days of the revocation.
  • Deletion of stored data can also be requested at any time by email (see Contact below); it will be completed within 7 days. Deleting data stored by this tool does not delete anything on YouTube; content on YouTube can be deleted through YouTube itself.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

In addition to the deletion process above, access can be revoked at any time via the Google security settings page: https://security.google.com/settings/security/permissions.
